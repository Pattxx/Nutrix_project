# Nutrix
AI-powered recipe generator &amp; calorie tracking web app

Project Overview <br>
Nutrix is a web-based application powered by AI that helps users track calories and macronutrients, manage food products, and generate recipes based on available ingredients.
Simply add what you have in your fridge, and Nutrix will suggest what you can cook, including step-by-step instructions, estimated calories, and macros.

Features <br>
Food product management 
Calorie & macronutrient tracking

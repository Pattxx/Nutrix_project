# Nutrix
AI-powered recipe generator &amp; calorie tracking web app

Project Overview <br>
Nutrix is a web-based application powered by AI that helps users track calories and macronutrients, manage food products, and generate recipes based on available ingredients.
Simply add what you have in your fridge, and Nutrix will suggest what you can cook, including step-by-step instructions, estimated calories, and macros.

Features <br>
AI-powered recipe generation - enter ingredients and receive recipe suggestions.
Calorie & macronutrient tracking - monitor nutritional values of meals and products.
Food management - add, edit, and remove products easily.
Responsive UI - clean and user-friendly interface.

Live Demo: https://nutrix-project.vercel.app/

Tech Stack
The project is built using:
React + TypeScript/JS
Vite 
Gemini AI API
OpenFoodFacts Api
REST API 
Node.js + Express
MongoDB

Installation & Setup

Clone the repository
git clone https://github.com/Pattxx/Nutrix_project.git
cd Nutrix_project

Install dependencies
npm install

Run the development server
npm run dev

Click on link in console.
App will automatically switch to local server
